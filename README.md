# 耶馬溪イベント 公式サイト

大分県中津市耶馬溪町のイベント情報をまとめた公式サイトです。GitHub Pages（GitHubが無料で提供する、静的なHTMLサイトをそのまま公開できる仕組み）で公開する想定で作られています。

- トップページ：`index.html`（「耶馬溪イベント」という総合案内ページ。現在は秋まつり1件を大きく案内しています）
- 秋まつり2026のページ：`autumn-fes/index.html`（本編。開催概要・プログラム・協賛企業・アクセスなど）

外部のライブラリやGoogle Fontsは一切読み込んでいません（表示が速く、依存が少ないシンプルな作りです）。

---

## フォルダ構成

```
LP-yabakei-event/
  index.html            … 総合トップページ
  autumn-fes/index.html … 秋まつり2026の本ページ
  assets/css/style.css  … サイト全体で使う共通デザイン（色・レイアウト）
  assets/img/           … 写真（英数字のファイル名に統一済み）
  CNAME                 … 独自ドメイン設定用（中身は yabakei-event.jp の1行のみ）
  404.html              … 存在しないページにアクセスされたときの案内ページ
  robots.txt / sitemap.xml … 検索エンジン向けの案内ファイル
  .nojekyll              … GitHub Pagesの内部処理（Jekyll変換）を無効にする空ファイル
```

## 内容を更新する方法（非エンジニア向け）

このサイトはプログラムではなく「文章が書かれたファイル（HTML）」でできています。難しいコマンドは不要で、**メモ帳のようにテキストを書き換えて保存するだけ**で内容を変更できます。

1. 変更したいページのファイルを開く（例：秋まつりの日程を直したいなら `autumn-fes/index.html`）
2. 直したい日本語の文章を見つけて書き換える
3. 保存する
4. Claude Codeで「この変更をコミット・pushして」と伝える（commit＝変更の記録を残す操作、push＝GitHub上に反映する操作。詳しい手順は毎回Claudeが日本語で説明します）
5. pushが終わると、数分でサイトに反映されます

**写真を差し替えたいとき**：`assets/img/` フォルダに新しい写真を入れ、HTML内の該当する `<img src="/assets/img/ファイル名">` の部分をそのファイル名に書き換えてください。写真は英数字のファイル名にすること、1枚あたり300KB程度を超える場合は縮小してから入れることをおすすめします（サイトの表示速度が遅くならないようにするためです）。

**出店者名を追加したいとき**：`autumn-fes/index.html` 内の「出店者」セクション（`<section class="section" id="exhibitors">` の中）に、協賛企業一覧（`id="sponsors"` セクション）と同じ書き方でリストを追加できます。

## ドメイン設定（yabakei-event.jp）の要点

このサイトは独自ドメイン `yabakei-event.jp` で公開する前提で作られています。

- `CNAME` ファイルに `yabakei-event.jp` と書いてあることで、GitHub Pages側に「このドメインで公開してほしい」と伝えています。
- 実際にこのドメインでアクセスできるようにするには、**ドメインの管理会社（お名前.com等）側でのDNS設定**が別途必要です（GitHub Pagesの標準的なドメイン接続手順に従います）。この設定はGitHubリポジトリの管理者権限が必要な操作のため、設定時に改めてご相談ください。
- ドメイン設定が完了するまでは、GitHubが自動で発行する `https://（GitHubユーザー名）.github.io/（リポジトリ名）/` のようなURLで確認できます。

## 注意事項

- 本サイトに掲載している情報（日時・会場・出店数など）は、プロジェクト側の確定情報にもとづいています。内容を変更する際は、必ず正しい情報かどうかを確認してから書き換えてください。
- 出店者の店名は、申込状況が確定してから追加する運用です（未確定のまま店名を掲載しない）。
